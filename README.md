Student Performance Dashboard (Power BI)

Overview

This project is an interactive Power BI dashboard developed to analyze student performance, academic achievements, and demographic insights.

The dashboard provides meaningful visualizations that help understand student performance across departments, subjects, attendance, scholarships, and other key indicators.


Features

- Interactive dashboard with page navigation
- KPI Cards
- Subject-wise performance analysis
- Student demographic insights
- Department-wise comparison
- Scholarship analysis
- Attendance analysis
- Interactive slicers
- Dynamic DAX measures


Dashboard Pages

1. Overview

- Total Students
- Average Score
- Average Attendance
- Pass Students
- Department Performance
- Scholarship Distribution
- Admission Year Trend
- Final Result Distribution

2. Student Insights

- Highest Score
- Average Age
- Gender-wise Performance
- City Distribution (Map)
- Final Result Analysis

3. Academic & Subject Performance

- Highest Subject Scores
- Student Performance Table
- Maths Performance
- English Performance
- Science Performance
- Computer Performance
